# Pinko App — نظام إدارة المبيعات والمخازن والتوزيع

نظام إلكتروني لإدارة تجارة الجملة والتجزئة للحلويات والسكاكر (شوكولاتة، بسكويت، ويفر، لبان، مصاصات).  
مبني بمعايير حماية للعمليات المالية والمخزنية مع التقيد التام بـ **عقد الاتصال الصارم (Online-Only Contract)**.

---

## 1. الهيكل الأساسي والمواقع الثابتة
النظام مهيأ مسبقاً بالمواقع والمخازن الثابتة دون أي تغيير أو اختلاق:
1. **المحل 1 — المخزن 1** (`shop1_warehouse1`)
2. **المحل 2 — المخزن 2** (`shop2_warehouse2`)
3. **سيارة التوزيع — إبراهيم** (`vehicle_ibrahim`) — موقع مخزون مستقل للسيارة.

---

## 2. قواعد الأمان وحماية المليارات
1. **عقد Online-Only:** لا يُسمح بتسجيل أي عملية بيع أو تحويل أو تحصيل محلياً عند انقطاع الإنترنت. تظهر الرسالة الواضحة:  
   «لا يوجد اتصال بالإنترنت. لم يتم تسجيل العملية.»
2. **دفتر الأستاذ غير القابل للتعديل (Immutable Stock Ledger):**  
   رصيد المخزون لا يُعدل مباشرة عبر SQL `UPDATE`. كل تغيير هو حركة مسجلة في `stock_ledger` مع مطابقة لحظية مع جدول `stock_balances`.
3. **العمليات المالية بالمليم/القرش (Piastres):**  
   جميع المبالغ تُحسب وتُخزن كأعداد صحيحة `BIGINT` بالقرش (100 قرش = 1 جنيه) لمنع أي انزلاق حسابي للكسور العشرية (Floating-Point Drift).
4. **مفاتيح عدم التكرار (Idempotency Keys):**  
   تمنع تكرار تسجيل الفواتير أو الخصم المزدوج للمخزون عند انقطاع الشبكة وإعادة المحاولة.
5. **مصفوفة الصلاحيات (RBAC):**  
   المالك (Owner)، مدير الفرع (Hanaa)، الكاشير (Mohamed)، أمين المخزن (Abdelrahman)، سائق التوزيع (Ibrahim). فحص الصلاحيات يتم في الخادم على مستوى كل طلب وقاعدة بيانات.

---

## 3. الحدود التشغيلية للباقات المجانية (Free-Tier Guardrails)
- **قاعدة البيانات الأساسية (Neon PostgreSQL):**
  - مساحة تخزين 1 GB لكل مشروع (المستخدم الفعلي أقل من 5 MB).
  - 100 Compute-Unit-Hours شهرياً (يتوقف تلقائياً بعد 5 دقائق خمول لتوفير الاستهلاك).
- **واجهة البرمجة (Cloudflare Workers):**
  - 100,000 طلب يومياً.
- **التخزين الاحتياطي (Cloudflare R2):**
  - مخصص حصراً للنسخ الاحتياطية المشفرة (10 GB-شهر مجاناً).

## 4. تشغيل وفحص المشروع محلياً

### تشغيل الخادم (Backend):
```bash
cd backend
npm install
npm test    # تشغيل اختبارات الثوابت الـ 14 الإلزامية
npm start   # تشغيل واجهة API على المنفذ 4000
```

### تشغيل وتجميع تطبيق الـ Handheld (Mobile Client):
```bash
cd mobile
npm install
npm run build   # بناء وتجميع حزمة الإنتاج
npm run dev     # تشغيل الخادم المحلي على المنفذ 3000
```

### تنفيذ تجربة النسخ الاحتياطي والاستعادة:
```bash
node scripts/backup_restore_drill.js
```
